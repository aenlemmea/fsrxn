## FSRXN 

From Scratch Reaction (FSRXN) is a from scratch (heh!) implementations 
of core 'more prevalent' Reactive Programming constructs, typically used in
Angular or Spring.

Mostly for learning.

> [!NOTE]
> Terminologies regarding various constructs differ in FSRXN's implementation.
> This is due to mostly as how the code is modelled rather than using Angular or Spring's terms.

### Scope

#### Angular Side:

- [x] Observer/Observable constructs
- [ ] Cancellation & Teardown
- [ ] Pipeable Operators
- [ ] Subject/BehaviourSubject (Hot Multicasting & State)
- [ ] High Order Operators
